# مواد منبع اصلی و خروجی‌های مشتق‌شده

این نسخه شامل چهار فایل منبعی است که کاربر دوباره بارگذاری کرده است. فایل‌های اصلی بدون بازنویسی در `source_materials/originals/` کپی شده‌اند؛ مرجع تصمیم‌های محصول جایگزین آن‌ها نیست.

## فایل‌های اصلی

- `originals/assets.md` — فهرست ۳۴۵ جفت‌ارز غیرفعال در حساب اعتباری طبق فایل ارائه‌شده. این فایل منبع حقیقت denylist است.
- `originals/intro-text.md` — توضیح چالش، اولویت موتور معاملاتی به UI، API/MCP، Backtest/Shadow و الزام دموی ویدئویی.
- `originals/task.md` — صورت مسئله، قوانین، فرمول بازدهی، خروجی‌ها و جدول پیشنهادی/ارائه‌شده داوری.
- `originals/هکاتون استارکوچ _ والکس.pdf` — PDF دوصفحه‌ای شرایط حساب اعتباری. نسخه PDF اصلی حفظ شده است.

## خروجی مشتق‌شده

- `derived/inactive_markets.json` — خروجی ماشینی parse شده از `assets.md`، با hash منبع و تعداد خطوط.
- `derived/inactive_markets.csv` — نسخه CSV همان denylist.
- `derived/SOURCE_SHA256.txt` — هش SHA-256 فایل‌های اصلی برای اثبات عدم تغییر بایت‌ها.

فهرست مشتق‌شده یک **denylist** است، نه allowlist. از آن به‌تنهایی نتیجه نگیرید که سایر بازارها همین حالا فعال و برای حساب خاص قابل معامله‌اند. allowlist نهایی باید از metadata فعلی API، active/Spot capability حساب و کم‌کردن denylist ساخته شود. هر سفارش باید دوباره از نظر symbol، حداقل مقدار، precision و موجودی اعتبارسنجی شود.

## نکته ایمنی مالی

PDF طرح را با «۰ تومان دارایی ورودی + ۵,۰۰۰,۰۰۰ تومان اعتبار دریافتی برای ۳ روز» معرفی می‌کند. `task.md` سرمایه مبنای رقابت را ۵ میلیون تومان می‌نامد. این را به معنی ۵ میلیون تومان پول شخصی + ۵ میلیون اعتبار تفسیر نکنید. موجودی واقعی و وضعیت حساب باید از API/پنل و برگزارکننده تأیید شود. PDF همچنین درباره کارمزد اعتبار و لیکوییدشدن هشدار دارد؛ بخش `docs/SOURCE_REVIEW_FA.md` را قبل از Live بخوانید.
